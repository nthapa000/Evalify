# Pattern 2 (MCQ + numerical), teacher side

Log in as **physics.teacher@evalify.local** (password in `demo.env`). Create one paper per folder.
Marking rule: the number counts within +-0.001; the written unit is ignored (no conversion, so `2.5 km`
for a key of 2500 m gets 0).

## Paper 2A: `Paper_2A/` (Motion and Measurement (2A))

| Wizard step | What to do |
|---|---|
| 1 Paper type | **MCQ + Numerical** |
| 2 Details | Name `Motion and Measurement (2A)`; MCQ **2** x **1 mark**; Numerical **3** x **2 marks** (total 8); upload `question_paper.pdf` |
| 3 Answer key | MCQ: Q1 = **A**, Q2 = **A** (or extract from `answer_key.pdf`). Numerical, type the number only: N1 = **50**, N2 = **2500**, N3 = **19.6** |
| 4, 5 | Negative marking off; Create |

On the sheet the numerical answers are questions 3, 4, 5 (units in the key: km/h, m, m/s).
Students: `../Student/Paper_2A/`, choose **Handwritten**.
